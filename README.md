# Python Blackjack

A blackjack game built in Python as a learning project. It starts as a terminal game and will grow into a graphical version with card images and animations.

## Status

🚧 In progress: Phase 1, the terminal game.

## Requirements

- Python 3.12+
- pytest (for running tests)

## Setup

```powershell
git clone <repo-url>
cd Black_Jack_Python
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install pytest
```

## Run the game

```powershell
python main.py
```

## Run the tests

```powershell
python -m pytest
```
